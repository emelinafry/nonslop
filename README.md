# Hot or Slop

**Can you still tell what a person made?**

Hot or Slop is a swipe game built for the [Non-Slop Hackathon](https://luma.com/32d8mqid) (Pangram × Kino × Capy × Paper). The theme asked: *what matters when you can generate anything, and can you explain your choices?* So we made a game about exactly that.

You get ten pieces: photos, short clips, and bits of writing. Some were made by people (several by people in the room), and some were generated by AI. Swipe right if a human made it, swipe left if AI did, and then say *why*. At the end you find out what kind of eye you have, and how you stacked up against an actual AI detector.

---

## How to play

1. **Swipe.** Right = human, left = AI. The buttons and arrow keys work too.
2. **Explain your choice.** Pick what gave it away: *too polished, too specific, weird detail, sounds like a person,* or *gut feeling.*
3. **See the truth.** The card flips over. Human pieces show who made them ("— Maya, 40 min ago"). Written pieces also show Pangram's verdict.
4. **Get your palate.** After ten cards you get one of five archetypes, each with its own pixel capybara:

| Correct | Archetype | |
|---|---|---|
| 0–20% | The Romantic | you see a soul in everything. even the bots. |
| 21–40% | The Skimmer | you read for vibes, not tells. |
| 41–60% | The Coin Flip | statistically a guess. spiritually undecided. |
| 61–80% | The Editor | you notice when something is too clean. |
| 81–100% | The Sommelier | you can taste the difference. Pangram should be nervous. |

You also get **your tell** (the reason you picked most often and how often it was right) and **you vs. Pangram** on the written pieces.

## AI detection with Pangram

We use the [Pangram](https://www.pangram.com) API for AI detection. The API key comes from Pangram and is only used by a small script, never in the browser.

- **What Pangram scores:** Pangram's detector reads **text**, so it scores every written piece in the deck. During the reveal, written cards show Pangram's verdict and confidence ("Pangram agrees — 96% human"), and the result screen compares your score on the writing with Pangram's.
- **Images and video:** these are labeled by us with ground truth (we know which ones we generated). Their reveal card says "Pangram reads text only" instead of showing a score.
- **Why we pre-score:** `npm run score` sends each written piece to Pangram ahead of time and saves the results to `src/data/pangram-scores.json`. That way the game never waits on the network during a live demo.

```bash
cp .env.example .env          # add your Pangram API key
PANGRAM_API_KEY=... npm run score
```

The script calls `POST https://text.api.pangram.com/v3` with your key in the `x-api-key` header and records `fraction_human` for each written card.

## Design: made in Paper with Claude

The design assets and UI were generated in **[Paper](https://paper.design)** using Paper's plugin with Claude. That covers the design system, every screen, the posters, and the characters:

- **Design reference board:** color palette, archetype washes, type options, and core elements (tape, stamps, buttons, "why" chips, tally marks)
- **Every game screen:** start, card, mid-swipe, why sheet, both reveals, calculating, and all five archetype result screens
- **Pixel capybaras:** one shared base character plus an outfit layer per archetype (flower crown, headphones, beanie and coin, reading glasses and red pen, beret and wine glass)
- **Three start-screen options and four posters**, including the split capybara: left half 1-bit dither (slop), right half full color (hot)

The look is a **watercolor sketchbook**: cold-press paper texture, cobalt for AI, vermilion for human, ink line work, handwritten notes in Gochi Hand, and type set in Fraunces. Everything is meant to look handmade, because the game is about spotting what's handmade.

The result screen's animated watercolor wash uses **[Paper Shaders](https://shaders.paper.design)** (`@paper-design/shaders-react`). Each archetype gets its own mesh gradient with the paper texture multiplied on top.

## Run it

```bash
npm install
npm run dev
```

Open the local URL in a narrow browser window, or on your phone over the same wifi (`npm run dev -- --host`).

### Before a demo

1. **Add media.** Put three photos and three clips in `public/media/` (`image-1.jpg`…`image-3.jpg`, `video-1.mp4`…`video-3.mp4`) or change the `src` paths in `src/data/cards.ts`. Missing files show a dashed placeholder.
2. **Add real writing.** Replace the placeholder written pieces in `src/data/cards.ts` with pieces people actually wrote, plus AI pieces generated from the same prompts. Set `isHuman` and `author`.
3. **Score with Pangram.** Run `npm run score` (see above).
4. **Optional sound.** Add short clips at `public/sfx/paper-swish.mp3` and `public/sfx/stamp.mp3`. We recorded real paper.

## Built with

- React + Vite + TypeScript
- Framer Motion for the paper physics: bottom pivot, 3D tilt, sliding light, spring release, and the flip reveal
- Paper Shaders for the result screen mesh gradient
- Pangram API for AI text detection
- Paper, with Claude, for design and UI
- Fonts: Fraunces, Gochi Hand, Inter (self-hosted, so it works offline)

## Project structure

```

  screens/       Start, Play, Calculating, Result
  components/    PlayCard (swipe + flip), WhySheet, Capybara, ArchetypeBackground (mesh), Tally, MediaContent
  data/          cards (the deck), archetypes, capybaras (pixel art), pangram-scores.json
  lib/           scoring + "your tell", haptics and sound
scripts/
  score-cards.mjs  pre-scores written cards with Pangram
public/assets/   paper texture
```
